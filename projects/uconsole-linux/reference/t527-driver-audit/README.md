- 核查对象是固定的 Avaota 与 WalnutPi 公开 BSP／构建／软件包，不把所有 T527 厂商镜像混成一套。

## 本次分类方法

| 分类 | 要求的证据 | 不能据此断言 |
| --- | --- | --- |
| 内核实现源码可见 | 构建规则、模块对象列表、对应C／汇编文件、选中配置 | 不等于无需修改即可编译6.18，也不等于已完整完成许可审查 |
| 源码＋预编译对象 | 链接／复制规则引用已提供的ELF relocatable或archive，缺少对应实现 | 不能只看到wrapper.c就说整个驱动均有源码 |
| 预编译模块、源码未找到 | 实际ELF `.ko`、modinfo／vermagic、检查过的源码／包范围 | 不用文件名或模块存在单独判定闭源 |
| 用户态二进制运行库 | ELF DYN／SONAME／动态依赖、调用wrapper／软件包来源 | 不等于内核驱动没有源码；也不等于该库一定没有开源上游 |
| 固件或微码 | 驱动加载／bootloader使用关系、原文件身份 | 不等于主CPU内核模块；其源码和重用条件另核对 |
| 未确认 | 尚缺源码、选择条件或文件／包字节 | 不把“未看见”写成“保证不存在” |

Mesa／glibc／FFmpeg等即使以预编译库放入镜像，也可能有公开上游源码；
还需核对供应方补丁、版本和实际重建输入，不能将所有 `.so` 一概称为闭源。
驱动源文件中的许可证、仓库许可证、第三方库／固件许可分开确认，不统一再许可。
