# Rust 宏分类

> `macro_rules!` 按模式展开 token；过程宏由单独的 proc-macro crate 在编译期处理和生成 token。

| 类型 | 使用形式 | 常见用途 |
| --- | --- | --- |
| [[1. 声明式宏 (Declarative Macros)\|声明式宏]] | `name!(...)` | 模式匹配、重复生成代码 |
| [[2. 过程宏 - 派生宏\|派生宏]] | `#[derive(Name)]` | 为结构体、枚举或联合体生成附加项 |
| [[3. 过程宏 - 属性宏 (Attribute Macros)\|属性宏]] | `#[name(...)]` | 处理或替换标注的项 |
| [[4. 过程宏 - 函数式宏 (Function-like Macros)\|类函数过程宏]] | `name!(...)` | 解析自定义输入并生成代码 |

外观类似不代表实现方式相同；普通内置属性也不一定是过程宏。能清晰地用函数或泛型表达时，优先考虑不引入宏的方案。
