# Rust 的 `?` 错误传播

> 对 `Result` 使用 `?`：成功时取得内部值，失败时提前返回错误。

## 示例

```rust
// 替代繁琐的错误处理
fn read_file() -> Result<String, std::io::Error> {
    let content = std::fs::read_to_string("file.txt")?;
    Ok(content)
}
// 相当于：
// match std::fs::read_to_string("file.txt") {
//     Ok(content) => content,
//     Err(e) => return Err(e),
// }
```

错误传播可能涉及错误类型转换；该示例的内外错误类型均为 `std::io::Error`。
