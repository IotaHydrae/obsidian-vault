既然我们已经了解了泛型的定义，现在来看看如何给这些泛型“立规矩”，这就是 **特性约束 (Trait Bounds)** 🔗。

在编写泛型代码时，你经常会发现自己需要泛型类型具备某种特定的功能。

### 2.1 为什么需要约束？

假设我们要写一个简单的函数，返回两个值中较大的那一个：

```rust
fn largest<T>(list: &[T]) -> &T {
    let mut largest = &list[0];

    for item in list {
        if item > largest { // ❌ 报错！
            largest = item;
        }
    }
    largest
}
```

这段代码无法编译。编译器会抗议：“嘿！我不确定 `T` 能不能进行大小比较。” 毕竟，不是所有的类型（比如一个空的结构体）都能用 `>` 来对比。

### 2.2 使用 Trait Bounds

为了解决这个问题，我们需要约束 `T` 必须实现了 `PartialOrd` 这个特性（Trait），它是 Rust 中专门负责大小比较的接口。

语法如下：

- **写法 A（直接约束）**: `fn largest<T: PartialOrd>(list: &[T]) -> &T`
    
- **写法 B（where 子句）**:

```rust
fn largest<T>(list: &[T]) -> &T 
where T: PartialOrd 
{ ... }
```
