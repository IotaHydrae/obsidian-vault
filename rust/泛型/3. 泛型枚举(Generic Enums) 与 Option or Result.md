# Rust 泛型枚举：Option 与 Result

> `Option<T>` 表示值存在或缺失，`Result<T, E>` 表示成功或失败；处理分支后才能取出其中的值。

```rust
fn divide(a: f64, b: f64) -> Result<f64, &'static str> {
    if b == 0.0 { Err("division by zero") } else { Ok(a / b) }
}

fn main() {
    let name: Option<&str> = None;
    println!("{}", name.unwrap_or("unknown"));

    match divide(6.0, 2.0) {
        Ok(value) => println!("{value}"),
        Err(error) => eprintln!("{error}"),
    }
}
```

- `Some(T)` / `None` 表示有值或无值；`Ok(T)` / `Err(E)` 表示成功或错误。
- `match`、`if let`、组合方法和 `?` 都可用于处理；`unwrap()` 在空值或错误时会 panic，不能代替错误处理。
- 两个泛型参数 `T` 和 `E` 分别决定成功值与错误类型。
