# Rust Trait Bounds

> 泛型函数只能使用其类型参数已声明支持的操作；用 `T: Trait` 或 `where` 添加约束。

```rust
use std::fmt::Display;

fn largest<T: PartialOrd>(items: &[T]) -> Option<&T> {
    let mut largest = items.first()?;
    for item in &items[1..] {
        if item > largest {
            largest = item;
        }
    }
    Some(largest)
}

fn print_pair<T>(a: &T, b: &T)
where
    T: Display + PartialOrd,
{
    println!("{a}, {b}; a > b: {}", a > b);
}

fn main() {
    assert_eq!(largest(&[2, 5, 3]), Some(&5));
    assert_eq!(largest::<i32>(&[]), None);
    print_pair(&2, &5);
}
```

- `T: A + B` 要求同时满足多个 trait；约束较长时使用 `where`。
- `PartialOrd` 允许不可比较的值，例如浮点数 `NaN`；示例没有处理这种情况，结果依赖输入顺序。需要全序时应选择适当的 `Ord` 类型或显式处理不可比较的情况。
- `T: Copy` 允许按位复制实现了 `Copy` 的值；不需要复制时优先传递引用。
