# Rust 泛型与生命周期

> 生命周期参数表达引用之间的有效期关系，不延长被引用值的实际存活时间。

```rust
use std::fmt::Display;

fn longest_with_announcement<'a, T>(x: &'a str, y: &'a str, ann: T) -> &'a str
where
    T: Display,
{
    println!("{ann}");
    if x.len() > y.len() { x } else { y }
}

fn main() {
    let x = String::from("Rust");
    let y = String::from("Generics");
    let result = longest_with_announcement(&x, &y, "compare");
    assert_eq!(result, "Generics");
}
```

返回值可能来自任一输入，因此其可用范围必须同时满足两个借用的约束。这里有多个输入引用，输出引用的来源无法按省略规则唯一推断，去掉 `'a` 会报 `missing lifetime specifier`。

```rust
struct Excerpt<'a, T> {
    part: &'a T,
}
```

`T: 'a` 表示 `T` 所包含的借用须满足 `'a`；它不要求一个实际拥有的 `T` 值一定存活到 `'a` 结束。某些位置（如 `&'a T`）会隐含所需的 outlives 约束，不必机械地重复标注。
