# Rust Trait 关联类型

> 关联类型由某个 trait 实现确定；泛型 trait 的不同参数则可以对应同一类型的不同实现。

```rust
trait Source {
    type Item;
    fn next(&mut self) -> Option<Self::Item>;
}

struct Counter(u32);

impl Source for Counter {
    type Item = u32;
    fn next(&mut self) -> Option<Self::Item> {
        self.0 += 1;
        Some(self.0)
    }
}

fn main() {
    let mut counter = Counter(0);
    assert_eq!(counter.next(), Some(1));
}
```

标准库 `Iterator` 同样通过 `type Item` 表示迭代器产生的类型；例如约束可写成 `I: Iterator<Item = u32>`。

```rust
trait Convert<Target> {
    fn convert(&self) -> Target;
}

struct Value(i32);
impl Convert<i32> for Value {
    fn convert(&self) -> i32 { self.0 }
}
impl Convert<String> for Value {
    fn convert(&self) -> String { self.0.to_string() }
}
```

这里 `Value` 可分别实现 `Convert<i32>` 和 `Convert<String>`。对于确定的 trait 参数和实现类型，一个实现中的关联类型是确定的；若 trait 自身带有不同的泛型参数，不能把这个结论误写为类型全局只能有一个关联类型。
