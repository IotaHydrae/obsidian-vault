# Noctalia 菜单掉帧的矩形渲染优化

> 先测配对 GPU 任务成本，再验证像素输出相同，最后观察实体交互。

## TL;DR

- 固定场景、指针事件、配置和渲染器；GPU 每次提交耗时不等于屏幕 FPS。
- 两补丁只缩短安全矩形内部 shader 路径，并跳过完全不可见的矩形提交。
- CM4 上 241 组 shader 字节相等、负对照被检出，用户确认交互改善；其他 GPU 重新验证。

## 方法：固定场景后分别验证成本与正确性

固定配置、壁纸、菜单页、指针事件和 GPU，使用相同操作重复比较原始与候选。
性能报告使用 GPU render 时间/提交任务；正确性用 RGBA8 字节相等、故意改色负对照和 CPU 可见性用例。
最后记录实体交互反馈。三者分别回答成本、输出保持和实际体验，不能由其中一项替代其他两项。

## 原因与补丁边界

两个补丁只改 `rect_program.cpp`：shader 对远离边框与圆角的安全内部提前返回距离；
CPU 仅对无可见填充/边框的矩形跳过提交，外阴影单独判断。源码支持的后续判断原则：

- Noctalia 5.3.0 的 `GlesRenderBackend::beginFrame()` 清空整个 surface，
  `RenderContext::renderScene()` 遍历场景。hover 导致 paint/layout dirty 后会请求重绘；
  小范围控件变化仍可能触发整块菜单绘制，不能只根据 CPU scene 提交耗时估计 GPU 成本。
- `[shell.panel] shadow=false` 与 `[shell] popup_shadows=false` 关闭对应阴影路径；
  单独将 `[shell.shadow] alpha=0` 不能等价替代，`surface_shadow::enabled()` 只看组件开关。
- 默认 panel 透明模式已经是 solid，backdrop 默认关闭。未核对最终有效配置与背景效果协议前，
  不应把模糊认定为掉帧原因。`config export full` 用于检查 GUI 状态是否覆盖 TOML。
- `control_center.width` 是 full-sidebar 基准值；compact 模式乘 0.85，none 模式乘 0.75，
  合法范围为 600–1200。缩小宽度可测试像素面积影响；音频页与 Home 页应在相同 sidebar
  设置下比较。Home 用户卡背景图没有独立配置开关，不能虚构关闭选项。

## 设备观察：定位结果与配对测量

用户在实体屏幕观察到点击顶部入口后，菜单内移动鼠标呈幻灯片效果。采样时没有编译任务，
固件保护标志为零、温度约 37°C，渲染器为真实 V3D；这些观察不能单独确定 GPU 瓶颈原因。
同一未锁屏控制中心采用 100 次相对指针事件、间隔 40 ms。原完整配置的一次观察为
65.9338 ms GPU render 时间/提交任务；关闭阴影与常规动画后一次为 27.84 ms，
再改为方角为 27.34 ms。该阶段同时改变多项效果和可能的 surface 边距，只用于定位；
方角没有明显额外收益，因此保留圆角。原配置的 `eglSwapBuffers` 慢调用约为 51–82 ms，
关闭效果后未捕获到 ≥50 ms 的慢 swap 日志。

之后固定紧凑配置、恢复壁纸，分别运行三轮相同指针操作：

| 渲染源码 | 三次 GPU render 时间/提交任务（ms） |
| --- | --- |
| 原始二进制 | 21.8655、22.0220、22.0389 |
| 安全矩形内部距离捷径 | 17.7736、18.2471、18.2573 |
| 上述补丁加完全透明矩形提前跳过 | 14.7749、14.6776、14.8755 |

原始三轮提交任务数为 113/111/112，最终两补丁为 111/113/109。这是 GPU 计数器按
提交任务归一化的测量，**不是屏幕 FPS**。用户随后在实体屏幕确认菜单“明显流畅了”；
该观察支持本次交互改善，不等于所有菜单、GPU 或桌面路径已经通过。

## 正确性证据与增量构建

两次单对象编译连同归档和链接分别为 9.17 秒、9.64 秒，没有整棵内核或桌面栈重编译。
实际 CM4 V3D 4.2.14.0 / Mesa 25.2.8 上，241 组原始/候选 shader 输出 RGBA8 字节
完全相同，零容差；故意改色的负对照被检出。CPU 绘制的 35 组可见性用例通过。
判据、运行入口和有限输入边界见矩形验证工具（工程源码：`image/packages/noctalia/validation/README.md`）。

## 工程配置与适用范围

当前工程默认配置在 150% 缩放下采用紧凑顶栏且隐藏 SSID 文本；阴影、常规动画和
边框关闭，控制中心 width 为 600，两种 sidebar 均为 compact。壁纸和圆角保留，
镜像默认锁屏为 300 秒，实机临时禁锁例外见[电源策略](../power/desktop-power-policy.md)。Waybar 保持默认，Noctalia 可选。

固定 Noctalia 5.3.0、CM4 V3D 4.2.14.0、Mesa 25.2.8，补丁属于Noctalia 配方（工程源码：`image/packages/noctalia/recipe.json`）。
锁屏过渡独立于普通动画，详见[电源策略](../power/desktop-power-policy.md)。
功能与资源比较见[外壳对比](labwc-shell-comparison.md)，不将本轮数值外推到 CM5 或 Rockchip。
