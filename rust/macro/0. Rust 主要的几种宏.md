
|分类|中文名称|定义方式|使用形式示例|主要特点与用途|常见代表例子|
|---|---|---|---|---|---|
|声明式宏|Declarative Macro|`macro_rules!`|`vec![1,2,3]`、 `println!()`|基于模式匹配，类似高级 match，能力有限但易写|`vec!`、`println!`、`format!`|
|过程宏|Procedural Macro|`#[proc_macro]` 等|— — — — — — — — — — — — — — — — — — — — — —|能操作 TokenStream / AST，能力非常强大|— — — — — — — — — — — — — —|
|└ 派生宏|Derive Macro|`#[proc_macro_derive]`|`#[derive(Debug, Clone, serde::Serialize)]`|专门给 struct / enum 自动派生 trait|`#[derive(Debug)]`、`Serialize`|
|└ 属性宏|Attribute Macro|`#[proc_macro_attribute]`|`#[get("/users")]`、`#[tokio::main]`|可作用于任意项（fn、mod、struct…），可修改或删除原代码|`#[test]`、`#[async_trait]`、`#[get]`|
|└ 类函数宏|Function-like Macro|`#[proc_macro]`|`sql!("SELECT * FROM users WHERE id = $1")`|看起来像函数调用，但输入是 token 流|`sql!`、`bitflags!`、`env!`（部分）|

Rust 宏体系基本上被分为这 **4 种最常见的实际用法**：

1. **声明式宏（macro_rules!）** 最常见、最简单，占日常代码中 80%+ 的宏使用量
2. **派生宏（derive）** 最常用的过程宏，几乎所有 serde、clap、thiserror、derive_more 等库都依赖它
3. **属性宏（attribute-like）** web 框架（axum、actix、rocket）、异步（tokio::main、async-trait）、测试以外的高级场景最常见
4. **类函数宏（function-like）** 领域特定语言（DSL）最爱，例如 sqlx::query!、diesel、bitvec!、tracing::instrument 等

### 快速记忆口诀

- 写简单重复代码 → 用 macro_rules!
- 想给 struct/enum 自动加 trait → 用 #[derive(...)]
- 想给函数/模块加特殊行为 → 用 #[xxxx] 属性宏
- 想写类似内置函数但超能力 → 用类函数宏 xxx!(...)
