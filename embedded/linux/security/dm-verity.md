# Linux dm-verity

> dm-verity 为只读块设备提供按需完整性验证；根哈希必须来自可信来源，才能建立完整的信任链。

## 原理与适用范围

- 数据块的哈希组织成树，读取时验证相关数据及哈希路径；根哈希用于锚定整棵树。
- 它检测受保护块的损坏或篡改，不提供加密，也不保护运行时内存或未纳入映射的数据。未读取的数据不会因为启用它而立即全部扫描。
- 校验失败的行为由配置决定，例如返回 I/O 错误、重启或其他模式；不要假设所有配置都会重启。
- 更新只读映像时需要重新生成哈希树，并安全更新或验证根哈希。是否启用 FEC、签名验证等取决于系统的内核配置和信任链设计。

相关内核选项包括 `CONFIG_DM_VERITY`、`CONFIG_DM_VERITY_FEC` 和 `CONFIG_DM_VERITY_VERIFY_ROOTHASH_SIG`；可用性和具体行为以目标版本的 device-mapper 文档为准。
