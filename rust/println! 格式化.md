# Rust 格式化输出

> `println!`、`eprintln!` 和 `format!` 共用格式字符串语法；`{}` 使用 `Display`，`{:?}` 使用 `Debug`。

| 格式 | 含义 | 示例 |
| --- | --- | --- |
| `{}` / `{:?}` / `{:#?}` | Display、Debug、展开的 Debug | `format!("{data:?}")` |
| `{:b}` / `{:o}` / `{:x}` / `{:X}` | 二、八、十六进制 | `format!("{:#x}", 42)` 为 `0x2a` |
| `{:>8}` / `{:<8}` / `{:^8}` | 宽度 8，右、左、居中对齐 | `format!("{:>8}", 42)` |
| `{:05}` / `{:#010x}` | 数字补零；后者包含十六进制前缀 | `format!("{:05}", 42)` 为 `00042` |
| `{:.3}` / `{:8.3}` | 浮点数精度，后者另指定最小宽度 | `format!("{:.3}", 3.14159)` 为 `3.142` |
| `{:e}` / `{:p}` | 科学计数法 / 指针格式 | `format!("{:p}", &value)` |

```rust
fn main() {
    let name = "Wooden";
    let data = vec![1, 2, 3];
    println!("name={name}, data={data:?}");
    assert_eq!(format!("{:08.3}", 3.14), "0003.140");
    assert_eq!(format!("{:>8}", 42), "      42");
}
```

宽度是最小宽度，不会截断较长的输出；直接捕获局部变量的格式字符串语法需要 Rust 1.58 或更新版本。
