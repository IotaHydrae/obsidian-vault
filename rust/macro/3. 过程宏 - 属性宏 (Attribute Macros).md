属性宏（Attribute Macros）非常强大，因为它们可以挂载在**函数、结构体、甚至模块**上，并且能够完全重写它们。

当你看到 `#[tokio::main]` 或 `#[router("/index")]` 时，本质上是把被标注的代码块“喂”给一个过程宏函数，由它加工后再吐出新的代码。

### 属性宏的函数签名 ✍️

与派生宏不同，属性宏接收**两个** `TokenStream`：

```rust
#[proc_macro_attribute]
pub fn my_attribute(attr: TokenStream, item: TokenStream) -> TokenStream {
    // attr: 括号里的参数（比如 "/index"）
    // item: 被标注的代码主体（比如整个函数）
    // ...
}
```

### 一个直观的例子：`#[logger]` 🪵

假设我们要写一个 `#[logger]` 宏，把它加在任何函数上，都能在函数开始执行时打印一行“正在调用 [函数名]”。

**被标注的代码：**

```rust
#[logger]
fn add(a: i32, b: i32) -> i32 {
    a + b
}
```

宏展开后的代码（大概样子）：

```rust
fn add(a: i32, b: i32) -> i32 {
    println!("正在调用 add..."); // 这是宏插入的代码
    a + b
}
```

### 深入思考 🤔

在属性宏的函数签名中：

1. `attr` 代表属性本身的参数。
    
2. `item` 代表被标注的整个函数体。

如果我们想实现上面的 `#[logger]`，宏需要从哪个参数里提取出 `add` 这个函数名，以便打印出“正在调用 add...”？

1. `attr`
    
2. `item`

> 2

没错！我们需要从 `item` 参数中提取信息。

由于属性宏直接替换了它所标注的代码块，`item` 包含了该函数的完整定义：包括它的名称、参数、返回类型以及函数体（大括号内的代码）。

### 属性宏的魔力：重写代码 ✍️

当我们编写 `#[logger]` 宏时，我们的目标是：

1. 解析 `item`（原来的函数）。
    
2. 提取函数名（用于打印日志）。
    
3. 构造一个新的函数，包含我们的打印逻辑和原来的函数逻辑。
    
4. 返回这个新函数的 `TokenStream`。

如果我们使用 `syn` 库解析，代码大概长这样：

```rust
#[proc_macro_attribute]
pub fn logger(_attr: TokenStream, item: TokenStream) -> TokenStream {
    // 将输入解析为一个函数
    let input = parse_macro_input!(item as ItemFn);
    
    let name = &input.sig.ident;     // 函数名: add
    let inputs = &input.sig.inputs;   // 参数: a, b
    let output = &input.sig.output;   // 返回值类型: i32
    let block = &input.block;         // 原始函数体: { a + b }

    // 构建新的函数实现
    let expanded = quote! {
        fn #name(#inputs) #output {
            println!("正在调用函数: {}", stringify!(#name));
            #block
        }
    };

    expanded.into()
}
```

### 属性宏 vs 派生宏 ⚖️

这是一个非常关键的区别：

- **派生宏 (`#[derive]`)**：只能**追加**代码。原来的结构体还在那里，宏只是在它后面补了一个 `impl` 块。
    
- **属性宏 (`#[...]`)**：是**替换**代码。宏拿走了原来的函数，还给编译器一个全新的函数。这意味着属性宏可以修改参数、改变返回值，甚至把一个函数变成一个结构体！

### 最后的思考 🧠

这就是为什么像 `#[tokio::main]` 这样的宏能把一个 `async fn main()` 变成一个普通的 `fn main()`，并在内部启动异步运行时。

我们已经一起探索了 Rust 宏的整个世界：从简单的**声明式宏**，到强大的**派生宏**，再到几乎无所不能的**属性宏**。

## 另一个例子

lib.rs

```rust
#[proc_macro_attribute]
pub fn log_elapsed(attr: TokenStream, item: TokenStream) -> TokenStream {
    let prefix = if !attr.is_empty() {
        let s = parse_macro_input!(attr as LitStr);
        s.value()
    } else {
        "Function".to_string()
    };

    let mut input = parse_macro_input!(item as ItemFn);

    let name_str = &input.sig.ident.to_string();
    let orig_block = *input.block;

    input.block = Box::new(syn::parse_quote! {{
        use std::time::{Instant, Duration};
         let start = Instant::now();
          let __result = (|| #orig_block)();
           let elapsed = start.elapsed();
        println!("[{}] {} took {:?}", #prefix, #name_str, elapsed);

        __result
    }});

    quote! { #input }.into()
}
```

main.rs

```rust
#[log_elapsed("UserService")]
fn fetch_user(id: u64) -> Option<String> {
    std::thread::sleep(std::time::Duration::from_millis(150));
    Some(format!("user-{}", id))
}

fn main() {
    println!("Hello, world!");

    fetch_user(150);
}

```
