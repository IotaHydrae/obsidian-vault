# DRAM 组织与时序基础

> DRAM 把数据放在需要周期刷新和受时序约束的存储单元中；容量、通道组织和实际访问延迟要结合器件与控制器配置判断。

## 组织与访问

| 概念 | 作用 |
| --- | --- |
| 存储单元 | 以电容电荷表示数据，需要感应和刷新 |
| bank / row / column | 决定控制器如何组织访问及复用内部资源 |
| rank / channel | 描述器件组合与控制器连接；具体位宽和数量取决于板级设计 |
| 激活、读写、预充电 | 行状态变化和列访问需要遵守器件规定的间隔 |
| 刷新 | 恢复单元电荷；刷新操作会占用部分访问机会 |

DRAM 的标称速率不等于应用可持续吞吐量。访问顺序、行命中率、总线宽度、通道、刷新、仲裁、缓存命中与其他主设备竞争都会影响测量结果。

## 嵌入式系统中的边界

- 时序参数、训练、板级信号完整性和电源由 SoC、DRAM 器件及固件共同决定；不要将其他板子的训练参数直接套用。
- 固件初始化可用内存后，内核还需按设备树或平台内存布局识别可用范围与保留区域。
- CPU 访问经过 cache / MMU；设备访问可能经过 DMA 和 IOMMU，不能把 DRAM 物理地址当作通用设备 DMA 地址，见 [[Kernel Address - Virtual and Physical]]。
- 怀疑硬件或时序问题时应结合温度、电压、频率、错误现象和可重复的内存测试，避免仅凭一次吞吐结果下结论。
