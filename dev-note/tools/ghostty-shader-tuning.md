# Ghostty CRT Shader：提高文字清晰度的调参方法

> 先减少辉光、色偏和大范围采样带来的视觉扩散，再独立评估动画、GPU 负载与可读性。

## TL;DR

- 在单独副本上调参，并与原版或关闭 shader 的画面对照。
- 文字更清楚不等于渲染更快，效果强度和采样成本是不同变量。
- 配置解析、GPU 编译、实际加载及视觉验收分别检查。

## 优先观察的效果

| 效果 | 清晰度问题 | 调整思路 |
| --- | --- | --- |
| Bloom / glow | 字形边缘扩散，暗字被亮区淹没 | 减少强度或范围，复核明暗背景 |
| 色差 | 边缘彩色重影 | 减少偏移幅度 |
| 扫描线与点阵 | 小字号细节丢失、对比度变化 | 降低遮罩强度或调整密度 |
| 曲面与几何变形 | 边缘字形拉伸 | 单独评估曲率与裁切 |
| 动画 | 空闲也持续重绘 | 按需求关闭动画并测量负载 |

参数名称和取值域由 shader 自己定义。不能把某份 CRT 变体的系数直接当成其他 shader 的推荐值；部分计算即使视觉强度降到零仍可能执行。

## 配置示意

```ini
custom-shader = /path/to/your-shader.glsl
custom-shader-animation = false
```

按所用 Ghostty 版本检查配置语法。配置校验成功不能证明 GPU 编译和实际加载成功；编译警告本身也不等于失败，应结合日志、画面及功能判定。

## 受控验证

固定窗口大小、缩放、字号、背景和文本样本，对比原版、修改版和无 shader。检查细小中文、ASCII、光标、选中区域及透明背景，并分别看静止和滚动状态。

先在独立预览会话验证，再设置为默认；需要当前窗口生效时按该版本支持的方式重载。保留可恢复的原文件和配置，问题复现时先撤回 shader，再判断终端本身。

参考：[Ghostty 配置参考](https://ghostty.org/docs/config/reference)、[1.2.0 Shader 与性能说明](https://ghostty.org/docs/install/release-notes/1-2-0)。
