# Rust 类函数过程宏

> 类函数过程宏以 `name!(...)` 调用，宏函数接收括号内 token 并返回替换调用位置的 token。

例如，将输入的结构体可见性改为 `pub`。在单独的 `proc-macro = true` crate 中添加 `syn = { version = "2", features = ["full"] }` 和 `quote = "1"`：

```rust
use proc_macro::TokenStream;
use quote::quote;
use syn::{parse_macro_input, ItemStruct};

#[proc_macro]
pub fn make_public(input: TokenStream) -> TokenStream {
    let mut item = parse_macro_input!(input as ItemStruct);
    item.vis = syn::parse_quote!(pub);
    quote!(#item).into()
}
```

在使用 crate 中调用 `make_public!(struct User { name: String });`，生成的结构体为公有，字段仍保留原有可见性。

过程宏可以在编译期执行 Rust 代码并解析较复杂的输入；这也会引入编译时依赖和调试成本。不要仅凭 `!` 的调用外观判断一个宏是 `macro_rules!` 还是过程宏。
