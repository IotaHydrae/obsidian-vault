# Rust 泛型函数与结构体

> 在名称后的 `<T>` 中声明类型参数；同一个 `T` 在一次实例化中代表同一个具体类型。

```rust
use std::fmt::Display;

fn display_item<T: Display>(item: T) {
    println!("Item: {item}");
}

struct Point<T> {
    x: T,
    y: T,
}

impl<T> Point<T> {
    fn x(&self) -> &T { &self.x }
}

impl Point<f32> {
    fn distance_from_origin(&self) -> f32 {
        (self.x.powi(2) + self.y.powi(2)).sqrt()
    }
}

fn main() {
    let p = Point { x: 3.0_f32, y: 4.0_f32 };
    display_item(p.x());
    assert_eq!(p.distance_from_origin(), 5.0);
}
```

- `impl<T> Point<T>` 声明 `T` 并为任意 `Point<T>` 提供方法；`impl Point<f32>` 只针对该具体类型。
- `Point { x: 5, y: 10.5 }` 不能满足两个字段共用一个 `T`。需要不同类型时可定义 `struct Point<T, U> { x: T, y: U }`。
- 泛型代码通常按具体类型单态化，可支持静态分发和优化，但可能增加生成的代码体积；实际性能应测量。

行为限制见 [[2. 特性约束 (Trait Bounds)]]。
