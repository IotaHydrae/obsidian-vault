# 离线候选内核安装

`tools/kernel_candidate.py` 只向离线根文件系统添加独立的诊断内核，保留原有启动文件和 `/lib` 布局。

## TL;DR

- 先挂载离线系统的根分区及启动分区，默认执行预览；核对路径后显式加 `--apply`。
- 使用新 release 和新镜像名。工具拒绝已有目标、普通 Pi 内核名及归档中的链接、特殊文件或越界路径。
- 不要把候选归档直接解压到 `/`；归档中的 `lib/` 目录可能替换 usrmerge 系统的 `/lib -> usr/lib`。
- 这个工具只添加文件，不生成 initramfs、不运行 depmod、不选择启动内核，也不连接或重启设备。

## 命令

```sh
python3 tools/kernel_candidate.py \
  --archive /path/to/candidate.tar \
  --root /mnt/offline-root \
  --release 6.18.57-v8-uconsole-s2idle-r1 \
  --image-name kernel8-s2idle-r1.img
```

所有四个参数必填。无模式参数或 `--dry-run` 仅验证并列出目标；`--apply` 创建文件，
不能与 `--dry-run` 同用。输出为人类可读的路径列表，不是稳定 JSON 接口。
退出码：0 为验证或安装完成；2 为拒绝的输入、归档或目标布局；1 为文件系统 I/O 或
清理错误；130 为捕获到中断，重试前应检查候选路径。参数语法错误由 argparse 返回 2。

`--root` 必须已存在且为目录，解析后的宿主 `/` 及其别名会被拒绝。
操作者负责确保它是离线系统，启动分区已挂载在正确位置，并且没有并发写入者。
路径本身不能证明系统处于离线状态；工具不识别物理磁盘，也不执行挂载或刷写。

## 接受的归档

只接受下列普通文件，其中 `<release>` 与 `<image-name>` 必须匹配参数：

```text
lib/modules/<release>/**
boot/config-<release>
boot/System.map-<release>
boot/firmware/uconsole/<image-name>
```

三个启动文件及至少一个模块目录中的文件必须全部存在。相应父目录和模块子目录条目
可以存在，但它们的所有权、时间和权限不应用到目标；空目录不会单独安装。
普通文件保留字节及 0777 范围内的权限，拒绝 setuid、setgid、sticky 等特殊位。
不复制归档的 uid/gid、时间戳、ACL 或扩展属性；新文件属于执行工具的账户。

路径必须是规范的相对 POSIX 路径，不含 `.`、`..`、空组件、反斜杠或控制字符。
重复路径、文件与目录重名、文件成为其他文件的父路径、链接、稀疏文件、设备节点和
其他额外内容均被拒绝。release 是单个字母数字标识符，可含 `._+-`；镜像名遵循相同
字符范围并以 `.img` 结束，不能使用 `kernel.img`、`kernel7.img`、`kernel7l.img`、
`kernel8.img` 或 `kernel_2712.img`。
这些默认名称按大小写不敏感比较，避免 FAT 启动分区把 `Kernel8.img` 当作同一个文件。

## 写入边界和失败处理

工具先完整读取归档到宿主临时目录，验证全部成员和所有目标后才创建候选文件。
已有候选 release 目录（包括空目录）、镜像、config 或 System.map 都会导致拒绝。
它不合并已有模块目录，也不覆盖任何已有文件。

允许两种库目录：真实 `/lib`，或精确的相对链接 `/lib -> usr/lib`，后者将模块写到
真实 `/usr/lib/modules/<release>`。除此之外，所有目标祖先都必须是真实目录；
目录文件描述符和 `O_NOFOLLOW` 阻止安装过程中跟随意外链接，`O_EXCL` 阻止覆盖。
工具不调用 tar 的 extract/extractall，也不把目录条目解压到根目录。

发生可捕获的写入错误或中断时，逆序删除本次创建且 inode 未变的文件和目录，
不递归删除原有目录。如果路径被其他进程替换或清理失败，错误会明确报告未完成的
清理。突然断电、进程被终止或存储故障可能留下独立的部分候选文件；这不是跨文件系统
原子事务，原有正常启动文件仍不属于写入集合。

## 验证依据

临时目录测试（工程源码：`tests/test_kernel_candidate.py`） 的判定依据是上述安装契约：
usrmerge 链接、原有库文件和正常启动文件的字节及权限不变；非法归档与目标冲突在
离线目录写入前拒绝；合法候选的字节和权限与输入一致；注入写入失败或可捕获的中断后删除本次输出。
中断覆盖首个和后续文件写入，并验证 CLI 返回 130、输出重试前检查候选路径的诊断。
同时覆盖真实 `/lib`、目标祖先链接、重复成员、路径穿越、特殊文件和默认预览模式。
这些测试不证明候选内核可启动、模块兼容或系统能够休眠唤醒。

```sh
python3 -m unittest discover -s tests -p test_kernel_candidate.py -v
```
