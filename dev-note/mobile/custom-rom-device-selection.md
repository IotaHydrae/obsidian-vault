# 为 LineageOS 选手机：先核对变体、解锁与可用业务

> 先满足具体型号可安装、实际设备可解锁和必需功能可用，再比较价格、内存与跑分；同系列名称或相同芯片不能代替兼容性证据。

## TL;DR

- 从 LineageOS 官方设备页核对型号、代号、变体和当前维护状态。
- 官方有 ROM 与这台机器能否解锁是两个条件，购买前分别确认。
- 跑分、内存容量和挂牌价格只回答部分问题，最终按日常任务与机况取舍。

## 购买前的最小核对表

| 条件 | 应取得的证据 |
| --- | --- |
| 型号和地区变体 | 系统／机身的完整型号与官方设备页列出的型号对应 |
| 官方支持 | 设备页、可用构建、维护状态及该变体安装指南 |
| Bootloader 解锁 | 目标实机的状态；未解锁时核实当前厂商条件与能否实际完成 |
| 固件与恢复 | 安装指南要求的固件版本、恢复方式及已知限制 |
| 日常业务 | 通话、相机、网络、VPN、通知及依赖认证的应用按需求测试 |
| 二手机况 | 账号退出、屏幕、电池、维修史和可验机／退货条件 |

“标准版”“Pro”“竞速版”可能是不同设备；官方支持一个不代表支持另一个。即使硬件接近，错误镜像也不可互刷。官方 FAQ 明确要求采用对应支持型号。

非官方移植按自己的发布来源、维护记录和实机缺陷评估，不能借同名官方设备的身份宣称兼容。维护和下载状态会变化，购买时重新核对，不把某次查询结果保存为永久推荐名单。

## 怎样比较性能与内存

- 同一基准的单次公开分数只描述那次条件，不直接等于微信启动、网页响应或持续负载体验。
- 比较代际性能时固定基准版本，并区分峰值、温控后的持续表现和真实应用调度。
- 12 GB／16 GB 是否有感取决于同时保留的应用、后台回收与负载；不能把容量差直接换算成流畅度差。
- 额外 RAM 的价值主要通过目标工作集的重载次数和切换延迟验证，参见 [内存压力](android-memory-pressure.md)。

屏幕、外放、振动、相机和外观也是日用条件。先写下自己的必要项，再在满足刷机前提的候选中比较，避免反复被单项跑分或大内存低价牵着走。

## 价格和刷机收益的边界

挂牌价、成交价、成色和库存是不同信息；历史页面只能作为当时样本，不能宣称现在可以买到。换电池、解锁与恢复成本也应计入实际预算。

刷入新系统不保证所有软件提速或认证通过。先定义希望解决的问题与验收任务，保留原系统和用户数据恢复方案；涉及 Root 的更新另见 [A/B OTA 与镜像匹配](android-ab-ota-root.md)。
