# MIPI-DSI 接口与显示模式

> 调试 DSI 屏幕时，先匹配物理接口、lane 数、像素格式和显示模式，再核对电源、复位、初始化命令及视频时序。

## 接口层次

- **DSI 协议**负责命令和像素数据传输；**DCS** 定义常见显示控制命令，厂商初始化序列还可能使用私有寄存器。
- **D-PHY** 常见连接包含时钟差分对和数据差分对；lane 数及速率必须由 host、面板和布线共同支持。
- **LP / HS** 是链路的不同工作状态。初始化命令使用 LP 还是 HS、是否需要读回或总线转向，要依据控制器与面板要求配置。
- **C-PHY** 的电气连接和编码不同，不能直接套用 D-PHY 的引脚或时序说明。

## 显示模式

| 模式 | 关注点 |
| --- | --- |
| Command mode | 通过命令更新面板内容；刷新方式、帧缓存和 TE 同步能力由面板决定 |
| Video non-burst sync pulse | 按视频时序发送，显式表达同步脉冲 |
| Video non-burst sync event | 按同步事件组织视频传输 |
| Video burst | 在视频时序约束下突发传输像素；不能概括为整帧只有一次同步 |

这些模式不直接决定屏幕分辨率、帧率上限或兼容性。带宽估算须包括像素数据、消隐及协议开销，不能仅用有效分辨率乘刷新率确定 lane 速率。

## 排查顺序

1. 核对接口引脚、供电、背光和复位极性。
2. 核对 lane 数、像素格式、显示模式与面板初始化序列。
3. 核对 pixel clock、水平/垂直 porch、同步宽度及 PHY 配置。
4. 结合 host 日志、面板状态和示波器测量确认问题；初始化命令发送成功不等于视频链路正常。
