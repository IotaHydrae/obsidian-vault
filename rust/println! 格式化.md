
Rust 中最常用的输出方式就是 println!（以及相关的 print!、format!、eprintln! 等），它们都使用相同的格式化字符串语法（来自 std::fmt 模块）。

### 基本用法

```rust
println!("Hello");                    // 普通字符串
println!("x = {}", 42);               // 默认格式（Display）
println!("调试: {:?}", vec![1,2,3]);  // Debug 格式（最常用调试）
println!("名字参数: {name}", name = "木头");  // Rust 1.58+ 支持（推荐！）
```

### 位置参数 vs 命名参数（Rust 1.58+ 强烈推荐命名参数）

```rust
// 位置（旧写法）
println!("{} + {} = {}", 1, 2, 3);

// 命名（新写法，可读性极高）
let x = 10;
let y = 20;
println!("{x} + {y} = {}", x + y);
```

### 常用格式说明符（: 后面的部分）

格式：`{ [argument] : [fill][align][sign][#][0][width][.precision][type] }`

| 写法示例              | 含义                | 示例输出（假设值=42）   |
| ----------------- | ----------------- | -------------- |
| `{}`              | 默认（Display trait） | 42             |
| `{:?}`            | Debug（最常用调试）      | 42             |
| `{:#?}`           | 美化版 Debug（多行缩进）   | （适合结构体、集合）     |
| `{:b}`            | 二进制               | 101010         |
| `{:o}`            | 八进制               | 52             |
| `{:x}` / `{:X}`   | 十六进制（小写/大写）       | 2a / 2A        |
| `{:#x}` / `{:#X}` | 带 0x 前缀           | 0x2a / 0x2A    |
| `{:e}` / `{:E}`   | 科学计数法（小写/大写）      | 4.2e1 / 4.2E1  |
| `{:p}`            | 指针地址（只用于指针/引用）    | 0x7ffee4c0a4ac |

### 对齐、宽度、填充

| 写法        | 说明              | 示例代码                         | 输出           |
| --------- | --------------- | ---------------------------- | ------------ |
| `{:>8}`   | 右对齐，宽度8         | `println!("{:>8}", 42);`     | `" 42"`      |
| `{:<8}`   | 左对齐，宽度8         | `println!("{:<8}", "hi");`   | `"hi "`      |
| `{:^8}`   | 居中对齐，宽度8        | `println!("{:^8}", "hi");`   | `" hi "`     |
| `{:0>5}`  | 用 0 填充，右对齐，宽度5  | `println!("{:05}", 42);`     | `00042`      |
| `{:#<10}` | 用 # 填充，左对齐，宽度10 | `println!("{:#<10}", "ok");` | `ok########` |
### 浮点数精度

|写法|说明|示例|输出|
|---|---|---|---|
|`{:.3}`|保留3位小数|`println!("{:.3}", 3.14159);`|`3.142`|
|`{:8.3}`|总宽度8，右对齐，3位小数|`println!("{:8.3}", 3.14);`|`3.140`|
|`{:0>8.3}`|用0填充，总宽度8，3位小数|`println!("{:08.3}", 3.14);`|`00003.140`|

### 常用组合示例（几乎覆盖 90% 日常场景）

```rust
fn main() {
    let name = "Wooden";
    let age = 25;
    let pi = 3.1415926535;
    let data = vec![1, 2, 3];

    println!("你好，{name}！");                        // 命名参数
    println!("年龄: {:3} 岁", age);                    // 右对齐宽度3
    println!("调试输出: {data:?}");                    // 普通 Debug
    println!("美化调试:\n{data:#?}");                  // 漂亮打印
    println!("PI ≈ {:.4} (科学计数: {:e})", pi, pi);   // 精度 + 科学计数
    println!("hex: {:#010x}", 0xdeadbeef);             // 带0x + 0填充
    println!("二进制: {:08b}", 42);                    // 8位二进制补0
    println!("指针: {:p}", &name as *const _);         // 打印地址
}
```

### 快速记忆口诀

- 想看内容 → `{}`
- 想调试 → `{:?}` 或 `{:#?}`
- 想对齐 → `{:>8}` / `{:<10}` / `{:^12}`
- 想补0 → `{:05}` 或 `{:0>8}`
- 想十六进制 → `{:x}` / `{:#x}`
- 想精确小数 → `{:.2}`
