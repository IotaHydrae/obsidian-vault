# Rust 泛型

> 泛型用类型、生命周期或常量参数表达可复用的代码；具体参数由使用处指定或推导。

- [[1. 泛型函数与结构体]]：定义泛型参数和实现方法。
- [[2. 特性约束 (Trait Bounds)]]：限制类型必须支持的行为。
- [[3. 泛型枚举(Generic Enums) 与 Option or Result]]：用枚举表达缺失值和错误。
- [[4. 关联类型 (Associated Types)]]：由 trait 实现确定关联类型。
- [[5. 泛型生命周期]]：表达输入和输出引用的有效期关系。

Rust 的泛型通常通过单态化生成针对具体类型的代码；这不意味着任意泛型程序一定更快或没有代码体积成本。
