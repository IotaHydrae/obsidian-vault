# Rust 声明式宏 `macro_rules!`

> 声明式宏用模式匹配输入 token，再按对应模板生成代码；重复模式适合处理可变数量的输入。

```rust
macro_rules! my_vec {
    ($($x:expr),* $(,)?) => {{
        let mut values = Vec::new();
        $(values.push($x);)*
        values
    }};
}

macro_rules! print_vars {
    ($($v:ident),* $(,)?) => {
        $(println!("{} = {}", stringify!($v), $v);)*
    };
}

fn main() {
    let values = my_vec![1, 2, 3,];
    let count = values.len();
    print_vars!(count);
    assert_eq!(values, [1, 2, 3]);
}
```

- `$x:expr` 匹配表达式，`ident` 匹配标识符，`ty` 匹配类型，`path` 匹配路径。
- `$(...),*` 用逗号分隔并重复零次或多次；`+` 为一次或多次，`?` 为零次或一次。`$(,)?` 允许尾逗号。
- `stringify!` 把输入 token 转成字符串，不对输入求值。
- 宏使用混合卫生性；局部变量等标识符的解析有特殊规则，但不能概括为所有名称都互不影响。导出宏引用自身 crate 中的项时可使用 `$crate`。
- 避免在展开中重复求值带副作用的表达式；完整示例见 [[macro example]]。
