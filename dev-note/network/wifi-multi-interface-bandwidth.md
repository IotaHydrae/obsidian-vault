# 两张 Wi-Fi 网卡能否叠加带宽

> 多一张网卡不自动增加单连接速度；要增益，既需要多路径调度，也需要真正独立且有余量的路径。

## TL;DR

- 两张网卡连同一 AP，可能仍争用同一信道、同一回程和同一宽带出口。
- 多个默认路由不等于单连接聚合，也不保证连接均匀分担。
- 先定位瓶颈，再决定改有线、换 AP 或部署多路径方案。

| 瓶颈 | 增加网卡通常不能直接解决的原因 |
| --- | --- |
| 代理节点或目标限速 | 两条本地无线链路仍访问相同受限服务 |
| 宽带出口 | 上游总容量没有增加 |
| 同一无线信道 | 新网卡也会占用共享空口 |
| 应用单连接路径 | 没有负责拆分和汇聚的机制 |

当单网卡已经成为瓶颈，而 AP、信道和上游尚有余量时，可通过按连接分流提高多连接总吞吐；效果要看实际路由、调度和并发负载。

MPTCP 可以让一个 MPTCP 连接使用多个子流，但需要匹配的内核、端点或代理支持及路径管理。不能只在本机插上网卡就假定远端普通 TCP 服务会聚合带宽。

验证时固定服务器、协议和文件，分别测单路径、并发总吞吐及多路径方案，同时记录 CPU、重传和无线状态。比较总吞吐与单文件速度时保持指标一致。
