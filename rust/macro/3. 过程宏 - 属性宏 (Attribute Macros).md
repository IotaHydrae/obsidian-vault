# Rust 属性过程宏

> 属性宏接收属性参数和被标注项两个 token 流，返回替换该项的 token 流。

## 给普通函数添加日志

在单独的 `proc-macro = true` crate 中添加 `syn = { version = "2", features = ["full"] }` 和 `quote = "1"`：

```rust
use proc_macro::TokenStream;
use quote::quote;
use syn::{parse_macro_input, ItemFn};

#[proc_macro_attribute]
pub fn logger(_attr: TokenStream, item: TokenStream) -> TokenStream {
    let mut input = parse_macro_input!(item as ItemFn);
    let name = input.sig.ident.to_string();
    let log: syn::Stmt = syn::parse_quote!(println!("calling {}", #name););
    input.block.stmts.insert(0, log);
    quote!(#input).into()
}
```

使用方式：`#[logger] fn add(a: i32, b: i32) -> i32 { a + b }`。解析并重新输出整个函数可保留可见性、签名和其他属性；此例仅演示普通函数，不处理参数校验，也未验证异步、特殊 ABI 等场景。

派生宏追加项，属性宏则用返回的 token 替换被标注项；宏代码不会自动保留未放入输出的内容。
